# 나의 일일 업무 보고 앱 · DAYLOG

스마트폰과 PC에서 사용하는 직원 업무보고·프로젝트 관리 앱입니다. 이미지의 원문은 `이미지_변환_텍스트.txt`에 보관했습니다.

## 구현 기능

- Supabase 이메일·비밀번호 로그인, 직원 가입 및 이메일 인증 안내
- 오늘 한 일 / 진행 업무 / 문제점 / 조치 내용 / 내일 할 일
- 임시저장, 수정, 제출, 관리자 승인·보완 요청, 수정 후 재제출
- 직원 화면과 관리자 화면 분리. 직원은 본인의 기록만, 관리자는 제출된 팀 보고서 조회
- 승인 완료된 보고서의 한글 PDF 직접 다운로드 (여러 페이지 자동 처리)
- 비공개 Storage에 사진·문서 첨부, 접근 권한이 있는 사용자만 다운로드
- 파일당 최대 10MB, 화면에서 보고서당 최대 10개 선택
- 프로젝트 등록·수정, 상태·진행률·완료 목표일, 추진 사항과 이력
- 제목·작성자 검색, 보고일·상태 필터
- 서버가 적용하는 상태 전환, 원문 보호, 본인 보고서 직접 승인 방지, 상태 변경 이력
- 데이터가 변경된 경우 버전 조건으로 오래된 화면의 덮어쓰기 방지
- 실제 데이터와 구분된 샘플 체험 (샘플은 서버에 저장되지 않음)

## 실제 연결

연결된 Supabase 프로젝트 `zaebytbxznokksgzegzp`를 사용합니다. 기존 `daily_tasks` 기능은 별도로 유지하며 새 앱은 `dr_` 접두어의 여섯 테이블과 `dr-report-files` 비공개 버킷을 사용합니다. 데이터베이스 구성은 이미 적용되어 있습니다. 같은 프로젝트에서 `schema.sql`을 다시 실행하지 마세요.

관리자 계정은 기존에 이메일 인증이 완료된 `topjjk@gmail.com`입니다. 이 앱의 기존 이메일·비밀번호로 로그인합니다. Supabase 관리 콘솔의 로그인 비밀번호와는 별개입니다. 비밀번호는 코드에 저장되어 있지 않습니다. 다른 직원은 앱에서 가입합니다. 추가 관리자 지정은 신뢰할 수 있는 서버 관리자가 `dr_profiles.role`을 변경해야 하며, 화면에서 스스로 승격할 수 없습니다.

`api.js`의 공개 publishable key는 브라우저 사용을 위한 키이며 비밀 관리자 키가 아닙니다. 사용자 권한은 RLS, SQL 트리거, Storage 정책에서 검증합니다. 서비스 키는 사용하지 않습니다.

## 실행

Node.js 22.12 이상 또는 24를 사용합니다.

```bash
cd daily-report-v2
npm ci
npm run dev
```

다른 Supabase 프로젝트를 사용하려면 `.env.example`을 참고하여 환경변수를 설정하고 `supabase/schema.sql`의 관리자 이메일을 변경한 후 새 프로젝트에 한 번 적용합니다.

## 검증

```bash
npm test
npm run build
```

`supabase/access-tests.sql`은 트랜잭션 내의 임시 계정을 사용하며 권한·상태 전환·이력을 검증한 뒤 모두 롤백합니다. 운영 배포 전에 신뢰할 수 있는 SQL 관리자 권한으로만 실행합니다.

`tests/cloud-e2e.mjs`는 별도 임시 검증 계정의 자격증명을 표준입력으로 받아 실제 로그인·저장·조회·업로드·승인·프로젝트 저장을 검증하는 관리자용 스크립트입니다. 임시 계정 생성·정리는 호출자가 담당합니다. 비밀번호·세션·토큰은 출력하지 않습니다. 일반 앱 실행에 필요하지 않습니다.

2026-11-24에 실제 클라우드 흐름과 SQL 권한 검증을 통과했습니다. 임시 검증 계정·파일·보고서·프로젝트는 정리했습니다. 한국어 PDF 1페이지와 긴 보고서 5페이지를 생성·렌더링하여 확인했습니다. 화면 검증은 샘플 체험으로 별도 진행했습니다.

## 사용 흐름

1. 로그인 또는 직원 계정 생성 후 이메일 인증
2. 새 업무보고 작성 → 사진·파일 선택 → 임시저장 또는 제출
3. 관리자는 관리자 화면 → 팀 업무보고 → 승인 또는 보완 요청
4. 보완 요청된 보고서는 직원이 수정 후 다시 제출
5. 승인 완료된 상세 화면의 PDF 저장 버튼으로 내려받기
6. 주요 프로젝트에서 목표·진행률·추진 이력을 따로 관리

PDF에는 보고서 내용·검토 의견·첨부파일 목록이 포함됩니다. 첨부파일 원문은 앱에서 별도로 다운로드합니다. 샘플 체험의 기록은 새로고침하면 초기화됩니다.
